# Skills do Projeto

Esta pasta guarda documentos de regras permanentes do projeto. Cada arquivo .md dentro desta pasta é uma "skill" que define padrões, comportamentos ou diretrizes específicas para o desenvolvimento.

**Importante:** Qualquer alteração de código ou nova implementação deve consultar as skills aplicáveis nesta pasta **ANTES** de começar a execução para garantir consistência e conformidade com a arquitetura e regras do projeto.
